# cupertino-dusk

A dark-only theme for Claude Code with an animated dusk scene: a ring-shaped campus among trees, the western hills,
and an indigo-to-peach sky, with twinkling stars, drifting clouds and a glowing window band. The motion respects
`prefers-reduced-motion`, so it holds still if you have reduced motion turned on.

It draws only in the Claude desktop and mobile apps, not in the terminal.

## Install

```bash
/plugin marketplace add rhealaloo45/pit-lane-claude-mods
/plugin install cupertino-dusk@pit-lane-claude-mods
```

Then restart the desktop app.
